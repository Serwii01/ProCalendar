# Pro Calendar — 用户指南

> 🇪🇸 [Versión en español](GUIA-DE-USUARIO.md) · 🇬🇧 [English version](USER-GUIDE.md)

**Pro Calendar** 是一款 Windows 桌面日历应用,完全在你的电脑上运行,并可与 **iCloud** 和 **Google 日历** 同步。你在 iPhone 或 Google 上创建的日程会出现在电脑上,反之亦然。应用还包含一个**待办事项**(to-do)模块。

你的数据属于你自己:全部保存在本机的本地数据库中,不会存放在第三方服务器上。

---

## 1. 安装

1. 从项目的 [`releases/`](../releases/) 文件夹下载 **`ProCalendar-Setup-1.0.0.exe`**。
2. 运行安装程序。无需安装 Java、MySQL 或其他任何东西——所有依赖都已内置。
3. 如果 Windows 弹出蓝色的 SmartScreen 警告("Windows 已保护你的电脑"),点击**更多信息 → 仍要运行**。出现该提示只是因为安装程序尚未进行数字签名,并非有害软件。

另外还有 **`ProCalendar-Portable-1.0.0.exe`**:免安装的便携版,适合放在 U 盘里使用。

> 应用将数据保存在 `C:\Users\<你的用户名>\.procalendar\`。卸载时不会删除该文件夹——重装后你的日程依然存在。

---

## 2. 快速上手

打开应用后,界面分为三个区域:

- **左侧边栏**:按来源筛选(全部 / Google / iCloud),在"日历"和"任务"视图之间切换,以及**立即同步**按钮。
- **中间区域**:日历主体,顶部有**日 / 周 / 月**视图切换。下方是优先事项、临近日程和本周统计面板。
- **右侧面板**:待办任务列表,带有快速添加表单。

### 创建日程

点击**新建日程**(或直接点击日历上的某个时间格)。在表单中可以设置:

- **标题**、**地点**和**备注**。
- **时间段**(开始和结束),或勾选**全天**。
- **目标日历**:你的某个 iCloud 日历、Google 日历,或选择**"仅本地"**(不上传到任何地方)。
- 日程**颜色**。

**编辑**日程:直接点击它。**删除**日程:打开后点删除;如果该日程来自 iCloud 或 Google,应用会提示它也将在云端被删除。

### 任务(待办)

在右侧面板(或侧边栏的**任务**视图)中,可以创建带优先级(高 / 中 / 低)和截止日期的任务。点击圆圈即可标记完成。也可以在日程详情中**把日程转换为任务**。

## 3. 与 iCloud 同步(iPhone/iPad/Mac)

iCloud 不允许第三方应用使用你的主密码,需要使用**应用专用密码**,一分钟即可生成:

1. 访问 [appleid.apple.com](https://appleid.apple.com) 并登录。
2. 进入**登录与安全 → 应用专用密码**,点击**生成**。Apple 会给你一串类似 `abcd-efgh-ijkl-mnop` 的密码。
3. 在 Pro Calendar 中打开**设置(⚙)→ 账户**:
   - **Apple ID**:你的 iCloud 邮箱。
   - **应用专用密码**:刚刚生成的那个。
   - 勾选**启用 iCloud 同步**,点击**保存更改**。
4. 点击侧边栏的**立即同步**。应用会自动发现你所有的 iCloud 日历(工作、家庭等)及其颜色。

之后同步是**双向的**:在 iPhone 上创建或修改的内容会出现在电脑上,反之亦然。

> 你随时可以在 appleid.apple.com 撤销该应用专用密码,不会影响你的账户。

---

## 4. 与 Google 日历同步

Google 日历不支持应用专用密码,因此需要在浏览器中授权(这是 Google 的官方机制):

1. 在**设置(⚙)→ 账户**中勾选**启用 Google 同步**,点击**保存更改**。
2. 点击**连接 Google 账户**。浏览器会打开:选择你的账户并同意日历权限。
3. 看到确认页面("✓ Google 已连接")后回到应用,设置中会显示**✓ 账户已连接**。

即使关闭或重启应用,连接也会保持。如需解除绑定,可在 [myaccount.google.com/permissions](https://myaccount.google.com/permissions) 撤销授权。

---

## 5. 自动同步

在**设置 → 同步**中可以:

- 开启/关闭**后台自动同步**。
- 设置同步**间隔**(分钟,默认 5)。

开启后无需任何操作:iPhone 或 Google 上的变更会自动出现。

---

## 6. 个性化

- **主题**:浅色、深色,或跟随 Windows 系统自动切换(**设置 → 外观**)。
- **语言**:西班牙语、英语或中文,即时生效(**设置 → 语言**)。

## 7. 常见问题与故障排除

**"iCloud 错误:缺少 apple-id / app-password"**
凭据尚未保存。请检查 设置 → 账户 并点击保存。

**"iCloud 凭据不正确"**
应用专用密码输错或已被撤销。请在 appleid.apple.com 重新生成。

**"Google 错误:没有 OAuth token"**
账户尚未连接:设置 → 账户 → 连接 Google 账户。

**应用提示端口被占用**
Pro Calendar 内部使用 8080-8090 端口,并自动选择第一个空闲端口。只有这 11 个端口全部被占用时才会出现该提示(极少见):关闭一些程序后重新打开即可。

**我的数据在哪里?如何备份?**
全部数据位于 `C:\Users\<你的用户名>\.procalendar\`。复制该文件夹即可完成完整备份。

**应用会把我的数据发送到别处吗?**
只会发送到你主动启用的服务(iCloud 和/或 Google),且仅限日历日程。未配置账户时,任何数据都不会离开你的电脑。

**"仅本地"日程会被上传吗?**
不会。它们永远不会离开你的电脑。
