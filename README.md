# Pro Calendar Desktop

Desktop app starter with Angular + Electron + Spring Boot + MySQL, ready for Google Calendar sync.

## Features
- Desktop shell with Electron.
- Angular UI starter.
- Spring Boot REST backend.
- MySQL persistence.
- Calendar, tasks, detail panel and modal-ready structure.
- Google Calendar integration scaffolding.

## Run
- Backend: `backend/mvnw.cmd spring-boot:run`
- Desktop: `cd desktop && npm install && npm run dev`
